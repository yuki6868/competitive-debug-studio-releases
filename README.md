# Competitive Debug Studio

競プロ初心者向けのデバッグ支援アプリです。

WA / TLE / RE の原因を見つけやすくするために、実行結果・失敗ケース・実行アニメーション・ヒートマップなどを確認できます。

## ダウンロード

最新版は Releases からダウンロードできます。

- macOS Apple Silicon: Competitive-Debug-Studio-mac-arm64.dmg

## 主な機能

- AtCoder向けのコード実行
- AC / WA / TLE / RE 判定
- 失敗ケースの保存
- user.py / ref.py / generator.py / config.yaml の編集
- 実行アニメーション
- TLE時の途中トレース表示
- 行実行回数ヒートマップ
- 実行時間分析
- コード構造の確認

## 対応環境

現在は macOS Apple Silicon 向けです。

Windows版は今後対応予定です。

## インストール方法

1. Releases から .dmg をダウンロード
2. .dmg を開く
3. Competitive Debug Studio.app を Applications に移動
4. アプリを起動

macOSで警告が出る場合は、右クリックして「開く」を選んでください。
